# Florian’s blog

[Read the blog](https://flocuc.github.io/blog/) · [Atom feed](https://flocuc.github.io/blog/feed.xml)

A small Jekyll site for reading notes and essays. GitHub Pages builds the root of `main`; HTTPS is enabled.

Add entries in `_posts/YYYY-MM-DD-slug.md` with this front matter:

```yaml
---
layout: default
title: "Daily reading — YYYY-MM-DD"
date: YYYY-MM-DD HH:MM:SS +0000
---
```

Use the actual publication timestamp with an explicit timezone. Historical entries retain their original publication times. Dates are displayed in UTC.

Write natural reading notes with direct article links. The index and Atom feed update automatically after a successful Pages build.
